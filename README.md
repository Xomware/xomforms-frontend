# xomforms-frontend

Angular frontend for **Xomforms** — a group availability scheduler (When2meet/Doodle done right).

Deploys to `xomforms.xomware.com`. See `docs/features/xomforms/PLAN.md` in the local working tree for the full spec, and `docs/features/xomforms/prototype/` for the Phase 0 drag-paint prototype.

## Setup

```bash
npm install
npm start
```
